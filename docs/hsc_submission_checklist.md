## 2. Complete Submission Asset Checklist

- [ ] Download official IIT Bombay master PPT template from the competition portal.
- [ ] Transfer slide content from `docs/presentation_deck_outline.md`.
- [ ] Verify that the slide count is strictly between 6 and 7 slides (excluding title/thank you if allowed by portal rules).
- [ ] Export as PDF and PPTX formats.

### Asset B: 3–5 Minute Demonstration Video
- [ ] Record screen capture following `docs/demo_script.md` (Target runtime: 3m 45s).
- [ ] Ensure audio commentary is clear and crisp (demonstrating English & Marathi toggle, reporting flow, authority triage, and public finance explorer).
- [ ] Export video in 1080p MP4 format (under size limit specified in portal, or host unlisted on YouTube/Google Drive as permitted).

### Asset C: Signed Annexure & Student Identity Verification
- [ ] Download Annexure from the portal dashboard.

- [ ] Scan signed annexure and College Student Identity Card (front & back) as clean PDFs.

### Asset D: AI-Tool-Use Disclosure Statement
- [ ] Open `docs/ai_tool_disclosure.md`.
- [ ] Fill in and verify the contribution percentages (Student % vs. AI Assistant %).
- [ ] Sign and date the document.

### Asset E: Source Code Repository Packaging
- [ ] Verify that all files pass the healthcheck test: `npm test` or `node test/healthcheck.js`.
- [ ] Ensure `.gitignore` excludes `node_modules`, log files, and any private documents.
- [ ] **Reminder:** Keep repository local until final review. Only publish or push to a remote repository when you have thoroughly reviewed the application and are ready to submit the repository link to the portal.
- [ ] If required by portal upload, generate a clean ZIP archive of the project folder (excluding `.git` and temporary files).

## 3. Final Step-by-Step Submission Procedure
1. **Login:** Access the official MY Bharat / VBYLD HSC 2027 portal.
2. **Track Selection:** Confirm track is set to **Governance and Civic Technology**.
3. **Upload PPT/PDF:** Attach the 6–7 slide deck in the designated slot.
4. **Attach Video Link:** Provide the demo video link or upload file.
5. **Upload Annexures:** Attach the signed student verification and AI disclosure document.
6. **Provide Code Link / Archive:** Enter the repository URL or upload ZIP.
7. **Final Submit:** Confirm before the countdown timer expires and save the submission confirmation receipt number.
